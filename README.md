# Vim 配置

这是一个用于维护个人 Vim 配置的仓库。目前仓库处于初始化阶段，后续配置应按功能逐步加入，并保持可理解、可验证和可回退。

## 项目约定

- 项目说明文档统一使用 Markdown（`.md`）。
- 所有会纳入版本控制的修改都要同步记录到 `CHANGELOG.md`。
- Git 提交按完整的逻辑批次组织，不按单次保存、单个文件或单处修改频繁提交。
- 提交消息采用 Conventional Commits 格式。

详细协作方式见 [CONTRIBUTING.md](CONTRIBUTING.md)，自动化协作者还应遵守 [AGENTS.md](AGENTS.md)。

## 文档索引

- [CONTRIBUTING.md](CONTRIBUTING.md)：开发流程、提交规范与检查清单。
- [CHANGELOG.md](CHANGELOG.md)：项目变更日志。
- [AGENTS.md](AGENTS.md)：适用于自动化协作者的仓库级规则。
